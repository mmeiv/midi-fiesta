# Windows MIDI Services metadata

`Windows.Devices.Midi2.winmd` is the compile-time API metadata used by CsWinRT to generate the MIDI host's projection. The application uses the in-box Windows API at runtime; the SDK runtime DLLs and transport packages are not included here.

Source: [Microsoft Windows.Devices.Midi2 0.99.92-preview.11](https://www.nuget.org/packages/Windows.Devices.Midi2/0.99.92-preview.11).
